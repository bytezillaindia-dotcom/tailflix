<product_requirements>
TailFlix is a mobile-first pet owner and dating app with a dark, premium theme, focusing on user interaction and engagement. The application features include a Splash screen, Phone/Email OTP login, a Home screen with navigation, AddPet profile creation, and user Verification. An Admin screen is present for managing pending verification requests and updating  status.

The primary current development is the **PetFeed screen**, which features:
-   **UI:** Swipeable, Tinder-style pet profile cards, displaying one at a time, with pet photo, name, age, breed, temperament tags, distance, and owner’s verification badge.
-   **Interactions:** Action buttons for Like (tennis ball), Skip (frisbee), Super Like (bone), and Golden Bone (golden bone). These use SVG icons, circular transparent touch targets, native feedback (ripple/haptics), and a visual press state (scale down 90%). Golden Bone includes a glow/sparkle animation.
-   **Filtering:** Only verified users/pets, exclude liked/skipped, match by distance and preferences (internal query, paginate 10 cards).
-   **Backend/API:** Track interactions in a likes table.
-   **Daily Limits:** Free users have a max of 10 daily actions (like + super_like + golden_bone). If exceeded, redirect to a redesigned **Paywall screen**.
-   **Premium Features:** Super Like and Golden Bone are premium-only. Golden Bone has an additional monthly limit of 5 for premium users.
-   **Matching:** Mutual likes/super likes/golden bones create a match, populating a  table and redirecting to a new **Match screen** with animations and Start Chat / Continue Browsing options.
-   **Admin Integration:** Admin users can toggle  status for any user.
-   **Guards:** Server-side guards enforce premium features, daily limits, and user verification for accessing critical features like PetFeed and chat.
</product_requirements>
